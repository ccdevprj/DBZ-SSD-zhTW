# v1.0 Apple Silicon compatibility

Verified on 23 November 2026 against [upstream v1.0](https://github.com/lming888/DBZ-SSD-zhTW/releases/tag/v1.0), commit `fc9ca9fbbee894d8390b5691d1236ee60b062a86`. The RC3 Mac launcher and icon are retained; the rebuilt app uses the v1.0 game engine and both updated Traditional Chinese language tables. The app reports version 1.0, build 4.

## Verification

- A locked, offline Rust 1.99.0 release build passed with the existing Swift launcher, arm64 architecture checks, local ad-hoc signature verification and plist validation. The nonfatal `rust-objcopy` debug-symbol stripping warning from the RC3 build also appeared here.
- The same user-supplied Japanese Rev 1 ROM and Klepto v1.02 `dbz102.ips` produce canonical CRC32 `A8CF4F2A`. The original-input digests and canonical output matched the checksums in the upstream README. A 600-frame headless boot passed.
- The unchanged upstream v0.3.9 base HD art ZIP matched the published size and SHA-256. A fresh install reported 73 portraits, 8,826 poses, 41 map layers and 77 backgrounds. Both Hong Kong and Taiwan translation profiles produced offscreen Metal snapshots and loaded 73 pictures and 8,819 poses from cache.
- In an isolated upgrade profile, the v1.0 launcher support code backed up all four old translation tables before updating them. It preserved the ROM cache and synthetic save and settings files byte for byte. The v1.0 engine loaded a copy of the RC3-installed base HD cache without reinstalling it. Existing player data was not used.
- `bash macos/test.sh` passed the synthetic migration, data-preservation and resource-refresh checks. The upstream scouter search and Traditional Chinese item-name regression tests passed.

## Updating

Build from the updated source with `bash macos/build.sh`; see [the Mac launcher instructions](README.en.md) or [繁體中文說明](README.md). Use the same user-provided ROM and IPS as before. The Mac data folder name and bundle identifier are unchanged. An existing compatible HD base pack does not need to be downloaded again. The Mac app does not download updates or bundle the ROM, IPS, HD pack, release-specific art overrides or the transformation voice.

This is a bounded native build and runtime check, not a full playthrough. First-run Finder dialogs, interactive F5/F9 save/load on v1.0, controller input, audible output and older macOS releases were not verified. No Android, iOS or tvOS build was produced or tested.
